# RUNAWAY — Interactive Login

> A login button that refuses to be clicked.

**Creative Web Lab · Experiment 001**

[Live Demo](#) · [Report an Issue](../../issues)

## ✨ Concept

RUNAWAY is a small interactive web experiment built around a simple idea: the login button tries to escape the pointer until the form is ready to submit.

The goal is to explore how micro-interactions can turn an ordinary authentication screen into a memorable experience.

## Features

- Interactive runaway CTA
- Email and password validation
- Password visibility toggle
- Success/authentication state
- Responsive layout
- Keyboard-friendly form controls
- Reduced-motion support
- No external dependencies

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## 🚀 Run locally

Clone the repository and open `index.html` in a browser. No build step or package installation is required.

## 🧠 What I explored

- Pointer-distance interaction
- DOM state management
- Form validation
- CSS transitions and visual feedback
- Responsive UI design
- Accessibility and reduced-motion preferences
